# IASC MHPSS Minimum Service Package · Nepali translation review space

Draft-review website for the Nepali translation of the IASC MHPSS Minimum Service Package (MSP). Not an official translation and not endorsed by the IASC; the original English edition is the binding and authentic edition (IASC 2022, CC BY-NC-SA 3.0 IGO). Search exclusion is advisory, not access control.

One page per document (20 documents in phases A, B and C), each holding the English source, the AI-assisted Nepali draft and a machine back-translation, sentence by sentence, for native-speaker review. Content lives in `data/site.json` and `data/units/*.json` (contract `msp-unit/v1`). See `PUBLISHING.md`.
